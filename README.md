# ศูนย์บัญชาการข้อมูลเศรษฐกิจ จังหวัดหนองบัวลำภู

รุ่น 0.4.0 — แยกเป็นไฟล์ละหน้า แก้ไขง่าย ไม่กระทบหน้าอื่น

## โครงสร้างไฟล์

```
index.html      หน้าปกจังหวัด          ← หน้าแรก
overview.html   ภาพรวมเศรษฐกิจ
gpp.html        GPP และการเติบโต
fiscal.html     การคลังภาครัฐ            [ข้อมูลจริง]
agri.html       ภาคเกษตร (6 หน้าย่อย)    [ข้อมูลจริง]
industry.html   อุตสาหกรรมและการผลิต
trade.html      การค้าและค่าครองชีพ
consume.html    การบริโภคและพลังงาน
labor.html      ตลาดแรงงาน
tourism.html    ภาคการท่องเที่ยว
otop.html       OTOP และเศรษฐกิจชุมชน    [ข้อมูลจริง]
household.html  ครัวเรือนและความเหลื่อมล้ำ [ข้อมูลจริง]

report.html     รายงานและบทวิเคราะห์
sources.html    แหล่งข้อมูลและที่มา
settings.html   ตั้งค่าระบบ
input.html      ระบบกรอกข้อมูลของหน่วยงาน

ds.css          สไตล์ร่วมทุกหน้า
ds.js           ฟังก์ชันร่วม แถบบน เมนู ตัวกรองเวลา tooltip
data1.js        ข้อมูลจริงชุดหลัก การคลัง เกษตร ราคา แรงงาน GPP
data2.js        ข้อมูลจริงชุดขยาย OTOP ท่องเที่ยว ครัวเรือน ประชากร ชลประทาน
assets/icons/   ไอคอน 3 มิติพื้นหลังโปร่งใส 24 ไฟล์
assets/         รูป 12 ไฟล์
Code.gs         Backend บน Google Apps Script
```

## จะแก้อะไร แก้ที่ไหน

| อยากแก้ | ไฟล์ |
|---|---|
| เนื้อหาหรือกราฟของหน้าใดหน้าหนึ่ง | ไฟล์ HTML ของหน้านั้น (มาร์กอัปกับสคริปต์อยู่ในไฟล์เดียว) |
| ตัวเลขข้อมูลจริง เช่น การคลัง เกษตร | `ds.js` ส่วน `const REAL = {...}` |
| ตัวชี้วัดหรือหน่วยงานเจ้าของข้อมูล | `ds.js` ส่วน `DATASETS` และ `SECTORS` |
| สี ขนาด ระยะห่าง ทุกหน้า | `ds.css` |
| รายการเมนูซ้าย | `ds.js` ส่วน `NAVI` |
| แถบบน ปุ่มต่าง ๆ | `ds.js` ฟังก์ชัน `buildShell` |

แถบบนและเมนูซ้ายสร้างจาก `ds.js` ทุกหน้า แก้ที่เดียวเปลี่ยนทั้งระบบ ไม่ต้องไล่แก้ 14 ไฟล์

## อัปโหลดขึ้น GitHub Pages

วางทุกไฟล์ไว้ที่รากของ repo และโฟลเดอร์ `assets` อยู่ระดับเดียวกัน

```
index.html  overview.html  gpp.html  fiscal.html  agri.html
industry.html  trade.html  consume.html  labor.html  tourism.html
area.html  report.html  sources.html  settings.html  input.html
ds.css  ds.js
assets/  (รูป 12 ไฟล์)
```

ชื่อไฟล์ต้องเป็นตัวพิมพ์เล็กทั้งหมด เพราะ GitHub Pages แยกตัวพิมพ์เล็กใหญ่
หากอัปโหลดโฟลเดอร์ `assets` ไม่ครบ ระบบจะขึ้นแถบเตือนสีแดงบอกทันที ไม่ปล่อยให้หน้าว่างเปล่า

## คุณสมบัติที่ยังทำงานเหมือนเดิม

- ตราจังหวัดและ favicon ฝังอยู่ในไฟล์ ไม่ต้องอัปแยก
- แก้ไขตารางได้ กดไอคอนดินสอบนแถบบน ค่าที่แก้บันทึกลงเบราว์เซอร์และคงอยู่ข้ามหน้า
- โหมดจอนำเสนอ กดครั้งเดียวแล้วระบบจะไล่เปิดหน้าอัตโนมัติทีละหน้า
- โหมดสว่าง/มืด สลับได้ จำค่าไว้ข้ามหน้า
- ตั้งค่าภาพพื้นหลัง สีหลัก และ URL ของ Apps Script ที่หน้า settings.html
- นำเข้าข้อมูลจาก Excel พร้อมแบบฟอร์มที่ระบบสร้างให้ ที่ input.html
